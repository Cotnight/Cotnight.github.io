## 这一课要交什么

这一节对应教材第一章 1.8 推理理论，课件在第 147–174 页。1.8 把"推理是否有效"从真值表的判定改成一串公式的推演：给一组前提与一个结论，逐行写出公式，每行标明依据。课件 1.8.1 列出四种动作——真值表法（1.8.2）、直接证法（1.8.3）、间接证法（1.8.4，含附加前提法与归谬法），第 173–174 页又补了分情况证明。

判定的依据是定义 1.8.1（教材原文）：设 $A$ 和 $C$ 是两个命题公式，当且仅当 $A\to C$ 为一重言式，即 $A\Rightarrow C$，称 $C$ 是 $A$ 的有效结论。一般地，若有 $n$ 个前提 $H_1,H_2,\dots,H_n$，且 $H_1\wedge H_2\wedge\cdots\wedge H_n\Rightarrow C$，则称 $C$ 是这组前提的有效结论。

考试的问法固定：给前提与结论，构造证明；或给一段自然语言的论证，先符号化再写出公式序列。真值表法能判定，却随变元数成倍变长，大题要的是公式序列。

八道推理题你已经逐题复算过，P、T 的用法、假言推理、拒取式、析取三段论、CP 都会使。这一课按三件事组织，正对着作业里还能改进的地方：

- **格式**：每一行写什么、依据栏怎么写，步骤分扣在这里；
- **选法**：结论长什么样，决定走直接证法还是间接证法；
- **规则**：八到十条蕴含式与几条等值式，看到什么形状写哪一条。

## 一张三列的证明表

直接证法（1.8.3 原文）：由一组前提，利用一些公认的推理规则，根据已知的等价或蕴含公式推演得到有效结论。它靠两条规则支撑：

- **P 规则**（前提引入规则）：前提在推导过程中的任何时候都可以引用。所以前提行不必都写在开头，课件 1.8.3 例3 就把四条前提穿插在推导中间。
- **T 规则**：在推导过程中，所证明的结论、已知的等价或蕴含公式都可以作为后续证明的前提；命题公式中的任何子公式都可以用与之等价的命题公式置换。前一句管蕴含式：整行引用，两行拼出一条新的。后一句管等值式：可以只替换公式的一部分。

每行一个公式，左起三列：序号、公式、依据。依据栏只有下面几种写法：

| 这一行怎么来的 | 依据栏 |
| --- | --- |
| 引用前提 | `P` |
| 引入附加前提 | `P（附加前提）` |
| 由前几行按蕴含式推得 | `T，2，3，拒取式`（教材与课件写成 `T，2，3，I12`） |
| 由前几行按等值式改写 | `T，1，E（德摩根）`（编号形式如 `E18`） |
| CP 收尾 | `T，4，10，CP`（附加前提行号，末行行号） |
| 归谬收尾 | 写出矛盾行，标 `T` 与行号；另起一句说明按归谬法 |

蕴含式与等值式的编号在教材 P43 表1-8.3、表1-8.4。编号记不准时写规则名，"引哪几行、按哪条"写全，步骤分就落得住；只写一个 `T` 而不写引用的行，那一步等于没写依据。

课件 1.8.3 例1：如果考试及格，那我高兴。若我高兴，那么我饭量增加。我的饭量没增加，所以我考试没有及格。

设 $P$：我考试及格；$Q$：我高兴；$R$：我饭量增加。论证表为 $(P\to Q)\wedge(Q\to R)\wedge\neg R\Rightarrow\neg P$。

| 序号 | 公式 | 依据 |
| --- | --- | --- |
| 1 | $P\to Q$ | P |
| 2 | $Q\to R$ | P |
| 3 | $\neg R$ | P |
| 4 | $\neg Q$ | T，2，3，拒取式 |
| 5 | $\neg P$ | T，1，4，拒取式 |

五行、三步推导，答卷上的篇幅就这么大。第 4 行从第 2、3 行来，第 5 行从第 1、4 行来，行号一目了然，阅卷人顺着数字就能核。写证明时最容易省掉的就是这两个数字。

## 直接证法：从结论倒推

前提一多，从第一条往下推会撞运气。稳的顺序是从结论倒推：先问"结论是哪种形状，它由哪条规则生成"，再补中间公式。这张表就是倒推的入口：

| 结论的形状 | 最后一步 |
| --- | --- |
| 单变元 $P$ | 找右端是 $P$ 的蕴含式：假言推理、析取三段论、化简 |
| 否定式 $\neg P$ | 拒取式（手里有 $P\to Q$ 与 $\neg Q$）；或归谬法 |
| 合取式 $P\wedge Q$ | 合成：分别证出 $P$ 与 $Q$ |
| 析取式 $P\vee Q$ | 附加：证出 $P$ 或证出 $Q$，再附加成 $P\vee Q$ |
| 蕴含式 $A\to B$ | 附加前提法：把 $A$ 加为前提，证出 $B$ |

课件 1.8.3 例3：$P\vee Q$，$Q\to R$，$P\to S$，$\neg S\Rightarrow R\wedge(Q\vee P)$。

结论是合取，最后一步是合成，所以要分别凑出 $R$ 与 $Q\vee P$。$Q\vee P$ 只与 $P\vee Q$ 差一次交换，$R$ 要靠 $Q$ 与 $Q\to R$，而 $Q$ 从 $P\vee Q$ 里析取得来，析取要消掉一支，就得先有 $\neg P$，$\neg P$ 正是 $\neg S$ 与 $P\to S$ 的拒取式。链条从这里接上：

| 序号 | 公式 | 依据 |
| --- | --- | --- |
| 1 | $P\to S$ | P |
| 2 | $\neg S$ | P |
| 3 | $\neg P$ | T，1，2，拒取式 |
| 4 | $P\vee Q$ | P |
| 5 | $Q$ | T，3，4，析取三段论 |
| 6 | $Q\to R$ | P |
| 7 | $R$ | T，5，6，假言推理 |
| 8 | $R\wedge(Q\vee P)$ | T，4，7，交换 E 后合成 |

前七行都在为第八行服务。倒推的好处是每一步都知道自己为什么写：第 3 行 $\neg P$ 的用处在第 5 行，手里有 $\neg P$ 才能从 $P\vee Q$ 里消去一支。

取课件 1.8.3 例4：$(P\to(Q\vee R))\wedge(\neg S\to\neg Q)\wedge(P\wedge\neg S)\Rightarrow R$。按上面的三列表写完整证明，然后逐条自查：

## 十条例式够用了

教材 P43 表1-8.3 列的是蕴含式：整行引用，两头拼。记的时候按"手里的形状"记，比按编号顺序记牢：

| 名称 | 式子 | 看到什么写它 |
| --- | --- | --- |
| 假言推理 | $P,\;P\to Q\Rightarrow Q$ | 手里有箭头和它的前件 |
| 拒取式 | $P\to Q,\;\neg Q\Rightarrow\neg P$ | 手里有箭头和后件的否定 |
| 析取三段论 | $P\vee Q,\;\neg P\Rightarrow Q$ | 一个析取加一个否定，消掉一支 |
| 假言三段论 | $P\to Q,\;Q\to R\Rightarrow P\to R$ | 两个箭头首尾相接 |
| 化简 | $P\wedge Q\Rightarrow P$（也 $\Rightarrow Q$） | 前提是合取，先拆开 |
| 合成 | $P,\;Q\Rightarrow P\wedge Q$ | 结论是合取，两边各凑一个 |
| 附加 | $P\Rightarrow P\vee Q$（也 $\Rightarrow Q\vee P$） | 结论是析取，凑出一支就够 |
| 假言易位 | $P\to Q\Rightarrow\neg Q\to\neg P$ | 箭头要倒过来用 |
| 二难推理 | $P\to Q,\;R\to S,\;P\vee R\Rightarrow Q\vee S$ | 两支各带一个箭头 |
| 归谬论 | $(P\to Q)\wedge(P\to\neg Q)\Rightarrow\neg P$ | 一个前件推出两个相反的后件 |

等值式在证明里只干一件事：把子公式改写成能接上规则的样子。四条最常用：

| 等值式 | 式子 | 用法 |
| --- | --- | --- |
| 蕴含消除 | $P\to Q\Leftrightarrow\neg P\vee Q$ | 要消箭头，或把箭头改成析取以便配合德摩根 |
| 德摩根 | $\neg(P\wedge Q)\Leftrightarrow\neg P\vee\neg Q$（对偶式同） | 否定号要推进括号、或从括号里提出来 |
| 假言易位 | $P\to Q\Leftrightarrow\neg Q\to\neg P$ | 箭头的后件要变成前件 |
| 输出律 | $P\wedge Q\to R\Leftrightarrow P\to(Q\to R)$ | 结论里连着两层箭头，拆成两次附加前提 |

等值式可以只替换一处子公式。作业里 $\neg(\neg P\wedge S)$ 整个换成 $P\vee\neg S$ 就是合法的一步，依据栏写 `T，行号，E（德摩根）`；从 $(T\to\neg U)\to\neg S$ 与 $T\to\neg U$ 得到 $\neg S$，依据栏写 `T，两行行号，假言推理`。这两处都是"否号与德摩根配合"的位置，改写本身没问题，能扣分的只有依据栏写没写全。

::: note 蕴含式与等值式的分工
T 规则的后半句只给等值式用：子公式能换。蕴含式不能换进公式内部，它是两条整行之间的一次跳跃。把 $P\to Q$ 里的 $P$ 换成某个更强的式子，那一步没有规则支持。
:::

## 附加前提法：先加再还原

1.8.4 的附加前提证明法适用于结论本身是蕴含的题，即 $(A_1\wedge A_2\wedge\cdots\wedge A_k)\Rightarrow A\to B$ 这一形状。做法是把 $A$ 当成额外的前提写进来，证明 $B$，最后一行写回 $A\to B$，依据标 CP。

课件 1.8.4 例2：前提 $P\to(Q\to R)$，$S\to P$，$Q$，结论 $S\to R$。

| 序号 | 公式 | 依据 |
| --- | --- | --- |
| 1 | $S\to P$ | P |
| 2 | $S$ | P（附加前提） |
| 3 | $P$ | T，1，2，假言推理 |
| 4 | $P\to(Q\to R)$ | P |
| 5 | $Q\to R$ | T，3，4，假言推理 |
| 6 | $Q$ | P |
| 7 | $R$ | T，5，6，假言推理 |
| 8 | $S\to R$ | T，2，7，CP |

首行第 2 条是附加前提 $S$，末行第 8 条把 $S$ 与 $R$ 合成 $S\to R$。中间第 3 到第 7 行只是把 $R$ 推出来，跟直接证法没有分别。所以 CP 的关键只有一处：**末行要还原**，依据写 CP 并引附加前提那一行的编号。

三处容易失分：

- 末行忘了还原，最后一行停在 $R$。这一串只能说明"$S$ 成立时 $R$ 成立"，答卷要的结论是 $S\to R$，最后一行必须写成蕴含并标 CP。
- 把结论整行当 P 行引入。能加为前提的只有前件 $S$；把 $S\to R$ 整行引入就是循环论证，全题判废。
- 附加前提的依据写成 `P`。写成 `P（附加前提）`，阅卷人才看得出这是 CP 的起点。

结论是两层箭头时，如 $A\to(B\to C)$，先用输出律把结论改写成 $A\wedge B\to C$，或者连加两次附加前提：先加 $A$，再在中间加 $B$，证出 $C$ 后写两行 CP 收尾。

::: quiz 改造 锚点：结论是蕴含就改走 CP
:::

::: quiz 排错 锚点：附加前提证完没有还原
:::

1. 两版的哪些行完全相同；

3. 哪一版更省行数。

## 归谬法：推出矛盾

定义 1.8.2（教材原文）：设命题公式集合为 $\{H_1,H_2,\dots,H_n\}$，若 $H_1\wedge H_2\wedge\cdots\wedge H_n$ 为永假式，则称 $\{H_1,H_2,\dots,H_n\}$ 是不相容的，否则称为相容的。

做法：把结论的否定 $\neg B$ 作为附加前提写进证明，推到出现一对矛盾（$R$ 与 $\neg R$，或某式与其否定），于是这组前提不相容，原推理有效。末行不写结论，写矛盾那一行，另起一句说明按归谬法。

课件 1.8.4 归谬法例1：$(P\to\neg Q)\wedge(\neg R\vee Q)\wedge(R\wedge\neg S)\Rightarrow\neg P$。

| 序号 | 公式 | 依据 |
| --- | --- | --- |
| 1 | $P$ | P（附加前提，结论的否定） |
| 2 | $P\to\neg Q$ | P |
| 3 | $\neg Q$ | T，1，2，假言推理 |
| 4 | $\neg R\vee Q$ | P |
| 5 | $\neg R$ | T，3，4，析取三段论 |
| 6 | $R\wedge\neg S$ | P |
| 7 | $R$ | T，6，化简 |
| 8 | $R\wedge\neg R$ | T，5，7，合成 |

由第 8 行得出矛盾，根据归谬法说明原推理正确。

两处容易失分：

- 假设写错。结论是 $\neg P$，附加前提要写 $P$（结论的否定），写成 $\neg P$ 等于把要证的东西当前提。
- 矛盾行之后没有结论句。第 8 行只写出 $R\wedge\neg R$，答卷最后要有一句"由第 8 行得矛盾，按归谬法，原推理有效"。

归谬论这条蕴含式与归谬法配合得很顺：推的过程中若同时得到 $P\to Q$ 与 $P\to\neg Q$，直接用归谬论整行得出 $\neg P$，比再拆矛盾省两行。

::: quiz 排错 锚点：归谬法的假设写成了结论
:::

## 前件是析取就分情况

课件第 173–174 页补的分情况证明：要证 $(P_1\vee P_2\vee\cdots\vee P_n)\Rightarrow Q$，只需对每个 $1\le i\le n$ 证明 $P_i\Rightarrow Q$。依据是一步等值演算：

$$
(P_1\vee\cdots\vee P_n)\to Q\Leftrightarrow(\neg P_1\wedge\cdots\wedge\neg P_n)\vee Q\Leftrightarrow(P_1\to Q)\wedge\cdots\wedge(P_n\to Q)
$$

课件补充例：证明 $((P\to Q)\wedge P)\vee((P\vee Q)\wedge\neg P)\to Q$ 是重言式。前件是两支的析取，逐支证：

情况 1，前提取 $(P\to Q)\wedge P$：

| 序号 | 公式 | 依据 |
| --- | --- | --- |
| 1 | $P\to Q$ | P |
| 2 | $P$ | P |
| 3 | $Q$ | T，1，2，假言推理 |

情况 2，前提取 $(P\vee Q)\wedge\neg P$：

| 序号 | 公式 | 依据 |
| --- | --- | --- |
| 1 | $P\vee Q$ | P |
| 2 | $\neg P$ | P |
| 3 | $Q$ | T，1，2，析取三段论 |

两支都推到 $Q$，前件的每一支都能推出结论，整个蕴含式是重言式。

写法上要守住两条：每种情况单独起一段并标"情况 1""情况 2"，各段的行号只在段内有效；末尾写一句"各种情况的结论相同，故原式成立"，把分情况这件事收口。情况数多于两种时同样处理，前提里往往就是几个析取支。

## 作业里的三处失分

**失分一：依据栏只剩一个 T。** 作业里写 `T` 或写规则的简称，不写引用的行号，复算时看得出推导对，考试按步骤给分时就吃亏。补法很简单：写每一行时先想"我引了哪几行"，再想"按哪条规则"，两样都写进依据栏。

**失分二：$P\to Q\Rightarrow P\to(P\wedge Q)$ 那道题走错了路线。** 结论是蕴含，前件是 $P$，本题就该用 CP：

| 序号 | 公式 | 依据 |
| --- | --- | --- |
| 1 | $P\to Q$ | P |
| 2 | $P$ | P（附加前提） |
| 3 | $Q$ | T，1，2，假言推理 |
| 4 | $P\wedge Q$ | T，2，3，合成 |
| 5 | $P\to(P\wedge Q)$ | T，2，4，CP |

五行写完。作业里设"前件真"之后直接假定 $P$ 的取值、$P=0$ 那一支写得乱，根因是把 $P\to Q$ 为真理解成了"$P$ 与 $Q$ 各有确定的值"。1.4 的真值表给出的是另一件事：$P\to Q$ 为真只意味着"$P=0$ 或 $Q=1$"这个二选一。分情况因此只有两支——$P=0$ 时前件假，$P\to Q$ 自动为真；$P=1$ 时由蕴含得到 $Q=1$，于是 $P\wedge Q=1$。

这个二选一也说明了 CP 为什么只写一支：附加前提 $P$ 正好就是 $P=1$ 那一支，把 $Q$ 推出来，蕴含就成立；$P=0$ 那一支按蕴含的真值规定自动成立，不必再证。凡是结论是蕴含、或前提里有蕴含的题，手上出现"某变元取 0 或取 1"的念头，先回到 CP 或归谬，别开真值表分支。

**失分三：把蕴含式当等值式用。** 等值式能替换子公式，蕴含式只能整行引用。作业里 $P\to Q$ 与 $\neg Q$ 得 $\neg P$ 是拒取式，一步到位；若试图把 $P\to Q$ 里的 $P$ 换成更强的式子再引用，这一步没有规则支持，写出来就判错。

::: quiz 应用 锚点：P→Q 推出 P→(P∧Q) 走哪条路线
:::
