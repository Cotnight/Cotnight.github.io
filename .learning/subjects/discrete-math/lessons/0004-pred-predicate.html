谓词、命题函数与量词

本节目标：说出客体、谓词与命题函数各是什么，并写出全称与存在两个量词命题的真值条件：有限论域上全称是逐一合取，存在是至少一项为真。

三列表在这里失效了

上一课交出的证明格式是这样的：前提逐条编号写 P，结论拆成蕴含，中间每一行标出引了哪几行、按哪条规则。实验一那台引擎更进一步，给它一组前提和一个结论，它穷举全部赋值，判出这个推理有效还是无效，判无效的还给出反例赋值。

拿它去判课件第 3 页开头那个推理：

  • 所有的人都是要死的。
  • 苏格拉底是人。
  • 苏格拉底是要死的。

设 P：所有的人都是要死的；Q：苏格拉底是人；R：苏格拉底是要死的。三段话压成三个字母，推理就是 (P\wedge Q)\to R。把 P=1、Q=1、R=0 代进去，前件真、后件假，引擎判"无效"，并把这一行赋值当作反例报出来。

引擎没有算错，(P\wedge Q)\to R 确实不是重言式。失效的是这份符号化本身：三句话里共有的那个"苏格拉底"，在公式里没有留下任何位置，第一句的"人"与第二句的"是人"也没有。课件第 3 页的判词是：命题逻辑以命题为基本单位，不再对原子命题进行分解，因而无法研究命题的内部结构、成分及命题之间的内在联系，甚至无法处理一些简单而又常见的推理过程。

课件第 4 页给的办法只有一句：将命题进行分解。第二章从这一句开始。本课只做第一件事：把原子命题拆成客体与谓词，再把"所有"与"存在"写成两个符号，并写出量词命题的真值条件。这两样东西课堂上已经讲过，本课按课件 2.1、2.2 的顺序走一遍，把每一步落成可写的式子。

把一句话拆成两截

课件 2.1 节把原子命题划分为客体和谓词两部分。

客体（课件原话）：可以独立存在的具体事物的或抽象的概念。课件举的例子是电子计算机、李明、玫瑰花、黑板、实数、中国、思想、唯物主义。客体也可称为主语。

谓词（课件原话）：用来刻划客体的性质或客体之间的相互关系的词。课件第 5 页用六个命题把两类谓词分开：

命题其中的谓词刻划什么
张明是个劳动模范是个劳动模范客体的性质
李华是个劳动模范是个劳动模范客体的性质
王红是个大学生是个大学生客体的性质
小李比小赵高 2cm…比…高 2cm客体之间的关系
点 a 在 b 与 c 之间…在…与…之间客体之间的关系
阿杜与阿寺同岁…与…同岁客体之间的关系

刻划一个客体性质的词称为一元谓词，刻划 n 个客体之间关系的词称为 n 元谓词。一般用大写英文字母表示谓词，用小写英文字母表示客体名称。课件把这六个命题记作：

  1. F(a)，a：张明；
  2. F(b)，b：李华；
  3. G(c)，c：王红；
  4. H(s,t)，s：小李，t：小赵；
  5. R(a,b,c)；
  6. S(a,b)，a：阿杜，b：阿寺。

其中第 1、2、3 条是一元谓词，第 4、6 条是二元谓词，第 5 条是三元谓词。课件在同一页里让字母各管一组命题：这里的 a 在第 1 条里指张明，在第 5 条里指一个点。这种重用只在"这一页一一对应"时成立，答卷上要把每个字母指谁都写清楚。

课件第 7 页给三条注，每一条后面都要用到：

  1. 单独一个谓词并不是命题，在谓词字母后填上客体所得到的式子称为谓词填式。
  2. 在谓词填式中，若客体确定，则 A(a_1,a_2,\dots,a_n) 就变成了命题。
  3. 在多元谓词表达式中，客体字母出现的先后次序与事先约定有关，一般不可以随意交换位置（如上例中 H(s,t) 与 H(t,s) 代表两个不同的命题）。

第 3 条容易被忽略：H 若解释为"…比…高 2cm"，H(s,t) 说的是小李比小赵高，H(t,s) 说的是小赵比小李高，一真一假。次序是谓词的一部分，写反了就换了命题。

填上客体才是命题

课件 2.2.1 节把上面那一步说得更细：设谓词 H 表示"是劳动模范"，a 表示客体名称张明，b 表示客体名称李华，c 表示这只老虎，那么 H(a)、H(b)、H(c) 表示三个不同的命题，但它们有一个共同的形式，即 H(x)。一般地，H(x) 表示客体 x 具有性质 H。这里 x 表示抽象的或泛指的客体，称为客体变元，常用小写英文字母 x,y,z 表示；相应地，表示具体或特定的客体的词称为客体常项，常用小写英文字母 a,b,c 表示。

定义 2.2.1（课件原话）：由一个谓词 H 和 n 个客体变元组成的表达式 H(x_1,x_2,\dots,x_n) 称为 n 元简单命题函数。

由定义可知，n 元谓词就是有 n 个客体变元的命题函数。当 n=0 时称为 0 元谓词。因此，一般情况下命题函数不是命题；特殊情况下 0 元谓词就变成一个命题。

课件第 13 页把这句话落成了判据：H(x)、L(x,y)、A(x,y,z) 本身并不是一个命题，只有用特定的客体取代客体变元 x,y,z 后，它们才成为命题。H(x) 与 H(a) 只差一个字母，前者没有真值，后者有。

复合命题函数：由一个或几个简单命题函数以及逻辑联结词组合而成的表达式。课件 2.2.1 例1：

  • 若 x 的学习好，则 x 的工作好。设 S(x)：x 学习好；W(x)：x 工作好，则有 S(x)\to W(x)。

课件 2.2.1 例2 要求把三个命题用 0 元谓词符号化：

  1. 2 是素数且是偶数。
  2. 如果 2 大于 3，则 2 大于 4。
  3. 如果张明比李民高，李民比赵亮高，则张明比赵亮高。

解（课件原话）：

  • (1) 设 F(x)：x 是素数，G(x)：x 是偶数，则命题符号化为 F(2)\wedge G(2)。
  • (2) 设 L(x,y)：x 大于 y，则命题符号化为 L(2,3)\to L(2,4)。
  • (3) 设 H(x,y)：x 比 y 高，a：张明，b：李民，c：赵亮，则命题符号化为 H(a,b)\wedge H(b,c)\to H(a,c)。

三小题填进去的都是客体常项，得到的都是 0 元谓词，都是有真值的命题。第 (3) 题值得和开头那个三段论对着看：H(a,b)\wedge H(b,c) 里的 b 同时出现在两个合取项中，前两句才被锁在一起，H(a,c) 才落得下来。苏格拉底那个推理缺的正是这一层联系；补上这一层之后，"所有"那个词还要另一个符号，本课后半段再解决它。

论域换了真值就变

课件 2.2.1 节末尾留了一句注意：命题函数中，客体变元在哪些范围内取特定的值，对命题的真值极有影响。课件用同一个式子 H(x,y)\wedge H(y,z)\to H(x,z) 给了三种解释：

H(x,y) 解释为论域这个式子的真值
x 大于 y实数永真式
x 是 y 的儿子人永假式
x 距 y 10 米平面上的点由 x,y,z 的具体位置定，可能是 1 也可能是 0

式子一个字没改，三种解释下一个永真、一个永假、一个不定。第二种解释判永假，原因在"儿子"这个关系：x 是 y 的儿子、y 是 z 的儿子，x 是 z 的孙子，后件为假而前件可以同真，整个蕴含式因此恒假。

课件第 17 页给这个范围起了名字：在命题函数中，客体变元的取值范围称为个体域，又称之为论域。个体域可以是有限事物的集合，也可以是无限事物的集合。宇宙间一切事物组成的个体域称为全总个体域。

课件 2.2.2 节第 3 条注意（一）（二）接着给了两条结论：

  1. 在不同的个体域，同一命题的符号化形式可能相同也可能不同。
  2. 在不同的个体域，同一命题的真值可能相同也可能不同。

第 2 条附带一个例子：设 R(x)：x 为大学生。如果个体域为大学里的某个班级的学生，则 \forall x R(x) 为真；若个体域为中学里的某个班级的学生，则 \forall x R(x) 为假。同一句 \forall x R(x)，换一个班，真值就翻。

这是本课第一处会直接扣分的地方：写下一个原子公式之前先写清论域，论域不写，公式就没有真值可谈。考试里的做法是开头一行"设个体域为……"或"以下取全总个体域"，两句话占一行，省不掉。

全称量词与存在量词

课件 2.2.2 节把量词分为全称量词和存在量词两种。

全称量词：对日常语言中的"一切""所有""凡""每一个""任意"等词，用符号"\forall"表示。\forall x 表示对个体域里的所有个体，\forall x F(x) 表示个体域里的所有个体具有性质 F。符号"\forall"称为全称量词。

课件 2.2.2 例3：在谓词逻辑中将下列命题符号化。

  1. 凡是人都呼吸。
  2. 每个学生都要参加考试。
  3. 任何整数或是正的或是负的。

解（课件原话，每题两种个体域各给一种写法）：

  • (1) 当个体域为人类集合时：令 F(x)：x 呼吸，则符号化为 \forall x F(x)；当个体域为全总个体域时：令 M(x)：x 是人，则符号化为 \forall x(M(x)\to F(x))。
  • (2) 当个体域为全体学生的集合时：令 P(x)：x 要参加考试，则符号化为 \forall x P(x)；当个体域为全总个体域时：令 S(x)：x 是学生，则符号化为 \forall x(S(x)\to P(x))。
  • (3) 当个体域为全体整数的集合时：令 P(x)：x 是正的，N(x)：x 是负的，则符号化为 \forall x(P(x)\vee N(x))；当个体域为全总个体域时：令 I(x)：x 是整数，则符号化为 \forall x(I(x)\to(P(x)\vee N(x)))。

存在量词：对日常语言中的"有一个""有的""存在着""至少有一个""存在一些"等词，用符号"\exists"表示。\exists x 表示存在个体域里的个体，\exists x F(x) 表示存在个体域里的个体具有性质 F。符号"\exists"称为存在量词。

课件 2.2.2 例4：在谓词逻辑中将下列命题符号化。

  1. 一些数是有理数。
  2. 有些人活百岁以上。

解（课件原话）：

  • (1) 令 Q(x)：x 是有理数，则符号化为 \exists x Q(x)。
  • (2) 当个体域为人类集合时：令 G(x)：x 活百岁以上，则符号化为 \exists x G(x)；当个体域为全总个体域时：令 M(x)：x 是人，则符号化为 \exists x(M(x)\wedge G(x))。

两个量词的中文标记只有下面这几组，看到它们就该落符号：

中文里的说法符号读法
一切、所有、凡、每一个、任意\forall x对个体域里的所有个体 x
有一个、有的、存在着、至少有一个、存在一些\exists x存在个体域里的个体 x

多个量词同时出现。课件 2.2.2 例5：命题"对任意的 x，存在 y，使得 x+y=5"，取个体域为实数集合，则符号化为 \forall x\exists y H(x,y)，其中 H(x,y)：x+y=5。这是个真命题。

课件第 25 页第 (4) 条注意：一般来说，当多个量词同时出现时，它们的顺序不能随意调换。同一套实数域、同一个 H(x,y)，\forall x\exists y H(x,y) 的真值为 1；若调换量词顺序后为 \exists y\forall x H(x,y)，其真值为 0。后者说的是"存在一个 y，它与每个实数 x 之和都是 5"，这样的 y 不存在。

量词的真值条件

量词命题在什么情况下为真，本课要交的就是这一条判据。课件第 25 页第 (5) 条注意给出的正是它：当个体域为有限集合时，如 D=\{a_1,a_2,\dots,a_n\}，对任意谓词 A(x)，有

\forall x A(x)\Leftrightarrow A(a_1)\wedge A(a_2)\wedge\cdots\wedge A(a_n)
\exists x A(x)\Leftrightarrow A(a_1)\vee A(a_2)\vee\cdots\vee A(a_n)

一句话：全称量词管的是合取，存在量词管的是析取。\forall x A(x) 为真，当且仅当论域里每个个体代进去 A 都真，只要有一个假，整句就假；\exists x A(x) 为真，当且仅当论域里至少有一个个体代进去 A 为真，全都假才假。

对照第一课那套东西看，这两个式子没有引入新的运算：n 个个体的合取就是 n 元合取，真值表里"全 1 才 1"那一列；存在量词取析取，"有 1 就 1"。量词做的事是把有限论域上的一次合取或一次析取写成一行，个体再多也不加长公式。

这条判据可以当场验一遍。Python 的 all 与 any 就是上面两条真值条件：all 逐项取合取，any 逐项取析取。

练习 改一行，看量词的真值怎么变

把下面五行存成 quant.py，跑一次：

students = ['张明', '李华', '王红']
hair = {'张明': True, '李华': True, '王红': False}
F = lambda x: hair[x]          # F(x)：x 长头发
print('forall:', all(F(x) for x in students))
print('exists:', any(F(x) for x in students))
$ python quant.py
forall: False
exists: True

第 1 步 · 找出是哪一个个体把合取拉成假。 加一行，把每一项的真值打出来：

print([(x, F(x)) for x in students])
$ python quant.py
forall: False
exists: True
[('张明', True), ('李华', True), ('王红', False)]

王红那一项是 False，合取链在这一项断开，\forall x F(x) 因此为假；存在量词只要有一项为 True 就成立，所以为真。

第 2 步 · 换论域。 把第一行改成 students = ['张明', '李华']，谓词与公式一个字不动，再跑一次。

$ python quant.py
forall: True
exists: True

同一个 F、同一个 \forall x F(x)，论域一变真值就翻。课件第 23 页那个"大学生"的例子是同一件事。

第 3 步 · 换量词。 把两行输出里的 all 与 any 对调，语句不动，两个结果互换。\forall 与 \exists 的差别全在"合取还是析取"这一步。

跑完这三步，把 hair 里三个值都改成 False 再跑一次，看两个量词各自给出什么——那一格是 \exists 的真值条件的极端情形。

默认全总个体域时

课件 2.2.2 节第 3 条注意（三）：约定以后如不指定个体域，默认为全总个体域。对每个客体变元的变化范围，用特性谓词加以限制。

特性谓词：限定客体变元变化范围的谓词（如例3中的 M(x)）。课件接着给的两句是符号化的第一个动作：

  • 对全称量词，特性谓词常作蕴含的前件，如 (\forall x)(M(x)\to F(x))；
  • 对存在量词，特性谓词常作合取项，如 (\exists x)(M(x)\wedge G(x))。

两边的接法不能互换。写成 \forall x(M(x)\wedge F(x))，说的是"一切事物都是人并且呼吸"，比"凡是人都呼吸"强得多；写成 \exists x(M(x)\to G(x))，全总个体域里取一块石头代进去，M(\text{石头}) 假、蕴含式真，整句随之成真——原句"有些人活百岁以上"被解释成了另一句话。

课件 2.2.2 例6 把这四句摆在一起（令 M(x)：x 是人，作特性谓词）：

原句符号化特性谓词接在哪边
所有的人都长头发\forall x(M(x)\to F(x))蕴含的前件
有的人吸烟\exists x(M(x)\wedge S(x))合取项
没有人登上过木星\neg\exists x(M(x)\wedge D(x))合取项，外面套否定
清华大学的学生未必都是高素质的\neg\forall x(Q(x)\to H(x))蕴含的前件，外面套否定

其中 F(x)：x 长头发，S(x)：x 吸烟，D(x)：x 登上过木星，Q(x)：x 是清华大学的学生，H(x)：x 是高素质的。

后两句的否定号加在整个量词命题外面，读作"并非所有……"与"不存在……"。这两条量词否定律属于 2-5，本课只按原句读：否定的范围是整个量词命题，符号写在最外层。下一课先讲辖域，看的就是"这个否定号管到哪儿为止"。

图的性质从这里写起

贯穿项目是关系与图算法工具包。第三篇写关系、第七章写图，那些性质用的就是本课的写法。设 E(x,y)：x 与 y 之间有一条边，图里"每个点都连到某个点"整句是

\forall x\exists y\,E(x,y)

它与例5的 \forall x\exists y H(x,y) 同一个形状。量词顺序在这里同样不能换：\exists y\forall x\,E(x,y) 说的是"存在一个点，它与所有点都相连"，那是另一种性质。现在能读出这一句，第七章讲连通性时会在同一处再见到它。
