谓词公式翻译与换名

本节目标：把含“所有”“有的”的中文译成谓词公式，并在公式里指出量词辖域、分开自由变元与约束变元，按换名与代入两条规则改写。

一句话里的三处翻错

上一课把原子命题拆成谓词填式，认了论域，也在有限论域上把量词展开成合取与析取。这一课处理完整的句子：先把整句中文写成谓词公式，再回头管公式里的变元。

老师课件 2.3 的翻译题从两句开始（第 34 页例2）：

  • 所有运动员都钦佩某些教练。
  • 有些运动员不钦佩教练。

课件给的解（令 L(x)：x 是运动员，J(y)：y 是教练，A(x,y)：x 钦佩 y）：

\forall x(L(x)\to\exists y(J(y)\wedge A(x,y)))
\exists x(L(x)\wedge\forall y(J(y)\to\neg A(x,y)))

第一句的 \exists y 落在 \forall x 的辖域之内，第二句的 \forall y 落在一个合取项的里面。量词套量词是翻译题的常态，两句的主结构都只有一层：第一句 L(x) 作蕴含的前件，第二句 L(x) 作合取项。

翻译的产物叫什么，课件第 31 页先定了名字：n 元谓词 A(x_1,x_2,\dots,x_n) 称为谓词演算的原子公式。定义 2.3.1 给出合式公式的五条：(1) 原子公式是合式公式；(2) 若 A 是合式公式，则 (\neg A) 也是合式公式；(3) 若 A,B 是合式公式，则 (A\wedge B)、(A\vee B)、(A\to B)、(A\leftrightarrow B) 也是合式公式；(4) 若 A 是合式公式，x 是 A 中出现的任何变元，则 (\forall x)A、(\exists x)A 也是合式公式；(5) 只有有限次应用 (1)~(4) 得到的公式是合式公式。

这五条说的是量词与联结词可以任意套，套出来的都合法。决定对错的在套法。整句翻译出错，落在三个具体位置上，下面按顺序一处一处过：

  1. 量词管到哪儿为止 —— 辖域画错，后面每个变元的归属跟着全错。
  2. 特性谓词接在哪一边 —— 全称接蕴含的前件，存在接合取项。
  3. 论域定了没有 —— 论域不写，特性谓词该不该出现、式子该写哪一种都没有依据。

第 1 处先讲：另外两处都要先读出式子才谈得上判对错。

量词辖域画到哪里

课件 2.4.1 定义 2.4.1（第 41 页原话）：在谓词公式中，形如 (\forall x)P(x) 和 (\exists x)P(x) 的部分，称为谓词公式的 x 约束部分。(\forall x)P(x) 或 (\exists x)P(x) 中的 x 叫做量词的指导变元或作用变元，P(x) 称为相应量词的作用域或辖域。在 \forall x 和 \exists x 的辖域中，x 的所有出现都称为约束出现，相应的 x 称为约束变元；P(x) 中除约束变元以外出现的变元称为是自由变元。

“作用域”与“辖域”是同一个词的两种叫法，本课统一写辖域。

判据一句：量词后面紧跟的那一对括号里的整段就是辖域。括号套括号时，外层辖域包住内层。课件第 41 页例1 给了两个式子：

  1. \forall x(H(x,y)\to\exists y(W(y)\wedge L(x,y,z)))
  2. \forall x(H(x)\to W(y))\to\exists y(F(x)\wedge L(x,y,z))

第 1 个式子里 x 的出现全在 \forall x 辖域内；y 有两处归属，H(x,y) 里的 y 在 \exists y 辖域之外，是自由出现，W(y) 与 L(x,y,z) 里的 y 在辖域之内，是约束出现。

第 2 个式子是第一处翻错的标本：x 在前件里受 \forall x 管，是约束变元；到了后件 F(x)、L(x,y,z) 里，\forall x 的辖域已经结束，同一个 x 成了自由变元。课件 2.4.2 开头那句说的正是这种情形：一个变元在同一个公式中既是自由出现又是约束出现，这样在理解上容易发生混淆。

式子约束出现自由出现
例1 第 1 式全部 x；W(y) 与 L(x,y,z) 里的 yH(x,y) 里的 y；z
例1 第 2 式前件的 x；L(x,y,z) 里的 yW(y) 里的 y；F(x) 与 L(x,y,z) 里的 x；z

第 42 页两条说明跟着来：

  1. n 元谓词公式 A(x_1,x_2,\dots,x_n) 中有 n 个自由变元，若对其中的 k（k\le n）个进行约束，则构成了 n-k 元谓词；如果一个公式中没有自由变元出现，则该公式就变成了一个命题。
  2. 一个公式的约束变元所使用的名称符号是无关紧要的，如 (\forall x)M(x) 与 (\forall y)M(y) 意义相同。

第 2 条是下一节换名的依据。第 1 条给了一条省事的判据：数自由变元的个数，就知道这个式子离命题还差几次约束。

换名只动辖域里的变元

课件 2.4.2 第 43 页的换名规则（对约束变元而言），原文两条：

  1. 约束变元可以换名，其更改的变元名称范围是量词中的指导变元以及该量词作用域中所出现的该变元，公式的其余部分不变。
  2. 换名时一定要更改为作用域中没有出现的变元名称。

第 44 页例1 给了两个换名：

  • \forall x(P(x)\to R(x,y))\wedge L(x,y) 换名为 \forall t(P(t)\to R(t,y))\wedge L(x,y)
  • \forall x(H(x,y)\to\exists y(W(y)\wedge L(x,y,z))) 换名为 \forall x(H(x,y)\to\exists s(W(s)\wedge L(x,s,z)))

第一个例子把范围说清了：x 在 \forall x 辖域里有 P(x)、R(x,y) 两处，两处一起换成 t；外层 L(x,y) 里的 x 不在辖域内，一个字母都不动。

第二个例子演示选名：内层 \exists y 的辖域里有 W(y) 与 L(x,y,z)，换成 s；同名的 H(x,y) 里的 y 在辖域外，仍作 y。规则第 2 条要求新名在这个辖域里没有出现过；x 已被外层 \forall x 占用、z 是自由变元，拿它们当新名会把两处归属搅在一起，所以课件挑了全新的 s。

两处常见错：

  • 换名时把辖域外的同名变元一起改了，写成 \forall t(P(t)\to R(t,y))\wedge L(t,y)。L 的第二个位置原本是自由变元 y，第一个位置的 x 也已不在任何量词底下，改完之后这个式子换了含义。
  • 新名挑了辖域里已经出现的字母，例如把内层 y 换成 z，得 \exists z(W(z)\wedge L(x,z,z))，L 的第三个位置被误绑到了量词上。

代入只代自由变元

第 45 页代入规则（对自由变元而言）：

  1. 对于谓词公式中的自由变元可以作代入，代入时需要对公式中出现该自由变元的每一处进行。
  2. 用以代入的变元与原公式中所有变元的名称不能相同。

例如对例1 中的公式 \forall x(P(x)\to R(x,y))\wedge L(x,y)，自由变元 y 用 z 来代入，得 \forall x(P(x)\to R(x,z))\wedge L(x,z)。

换名与代入管的是两种不同的变元，两套规则并排：

对比项换名代入
对象约束变元自由变元
改哪些位置指导变元，以及该辖域内该变元的每一处公式中该自由变元的每一处
新名字的限制辖域里没有出现过的名称与原公式里所有变元的名称都不同
改完的后果公式意义不变换成另一个谓词，赋值时把新变元代进去

代入那列的第 3 行容易被忽略：y 换成 z 时，z 不能是公式里已有的字母，否则新旧变元撞名，逐处数起来就分不清哪处是换来的。

练习 第 1 步 · 三个式子：标辖域、点自由变元、换名

拿一张纸，把下面三个式子各抄一行，做三件事：给每个量词画出辖域（用括号或弧线都行）、把自由变元圈出来、按换名规则换掉那个既约束又自由的字母。

  1. \forall x(P(x)\to Q(x))\wedge\exists y\,R(y)
  2. \exists x(A(x)\wedge\forall y(B(y)\to L(x,y)))
  3. \forall x(H(x,y)\to\exists y(W(y)\wedge L(x,y,z)))

对照答案：

式子辖域自由变元换名结果
1两个量词各管自己后面那对括号无不必换，x、y 各只出现一种形式
2\exists x 管到最外层括号；\forall y 只管 B(y)\to L(x,y)无不必换
3\forall x 管到最外层；\exists y 管 W(y)\wedge L(x,y,z)H(x,y) 里的 y；z\forall x(H(x,y)\to\exists s(W(s)\wedge L(x,s,z)))

第 1 题值得多看一遍：两个量词并列着出现，谁也不在谁的辖域里，所以 x 与 y 两处都是约束变元，但各归各的量词。第 3 题的两个 y 一处自由一处约束，换掉内层那个即可，外层那个原样留着——这正是课件第 44 页例1 的第二个换名。

特性谓词接哪一边

课件 2.3 例1（第 32–33 页）四题：

  1. 凡正数都大于零。
  2. 存在小于 2 的素数。
  3. 没有不能表示成分数的有理数。
  4. 并不是所有参加考试的人都能取得好成绩。

课件的解（原话）：

  • (1) 令 F(x)：x 是正数，M(x)：x 大于零，则符号化为 \forall x(F(x)\to M(x))。
  • (2) 令 E(x)：x 小于 2，S(x)：x 是素数，则符号化为 \exists x(E(x)\wedge S(x))，真值为 0。
  • (3) 令 D(x)：x 是有理数，F(x)：x 能表示成分数，则符号化为 \forall x(D(x)\to F(x))，或 \neg\exists x(D(x)\wedge\neg F(x))，真值为 1。
  • (4) 令 M(x)：x 是人，Q(x)：x 参加考试，H(x)：x 取得好成绩，则符号化为 \neg\forall x(M(x)\wedge Q(x)\to H(x))，或 \exists x(M(x)\wedge Q(x)\wedge\neg H(x))。

四题是同一条接法：全称后面接蕴含，特性谓词作蕴含的前件；存在后面接合取，特性谓词作合取项。第 (3)(4) 两题还多一层：题面是“没有…”“并不是所有…”，否定号加在整个量词命题的外面。

第 (2) 题说明特性谓词为什么省不掉。论域取全总个体域时，E(x) 与 S(x) 两项都得写，缺一项，x 就可能取到不满足条件的那种客体。真值为 0 是因为“小于 2”与“是素数”没有共同满足者：素数里最小的那个是 2，它不小于 2。

接错边的三种写法，以及各自被读成了什么：

错写读成什么改法
\forall x(F(x)\wedge M(x))一切客体都是正数，而且都大于零前件改成蕴含
\exists x(E(x)\to S(x))取一块石头代进去，前件为假、蕴含为真，整句成真换成两个合取项
\exists x(L(x)\to\forall y(J(y)\to\neg A(x,y)))非运动员使前件为假，句子白送一个真值L(x) 作合取项

论域换了写法跟着换

上一课那条约定（课件 2.2.2 第 3 条注意（三））：以后如不指定个体域，默认为全总个体域；对每个客体变元的变化范围，用特性谓词加以限制。课件 2.3 例1 的四个解都按这条写，特性谓词一个不落。

论域一旦指定，写法随之变。仍以第 (2) 题“存在小于 2 的素数”为例：

个体域符号化真值特性谓词的去留
全总个体域\exists x(S(x)\wedge E(x))0两项都要
全体素数的集合\exists x\,E(x)0S(x) 可省
全体整数的集合\exists x(S(x)\wedge E(x))0两项都要

第二行省掉 S(x) 的理由：论域里每个客体本来都是素数，再写一遍是重复。第三行不能省：整数里有 4、6、9 这些不是素数的客体，光写 E(x) 会把它们也算进来。真值三行都是 0，但“为什么是 0”要按各自论域说：第二行是“有一个素数小于 2”，另外两行还要多一层“它同时是素数”。

考试里这一步落在卷头第一行：设个体域为……。这一行决定后面式子该怎么写；论域换了而不把式子重新读一遍，往往整题失分。

只有与除了

课件 2.3 的例题里没有“只有”“除了”这类限定词，考试却常用。这两种都能用上面那套推出来，方向与否定各要小心一处。

只有 P 才 Q：这句说的是 Q 成立时 P 一定成立，P 是必要条件。设论域为全体学生，P(x)：x 有借书证，Q(x)：x 把书借走，则

\forall x(Q(x)\to P(x))

写成 \forall x(P(x)\to Q(x)) 就成了“有借书证的一定把书借走”，方向反了。凡遇到“只有”“必须”“除非”，先分清哪一句是结论、哪一句是条件，条件写进后件。

除了 A，其余都 B：先把论域收窄，再用否定把例外项排除。设 T(x)：x 是桌上的书，M(x)：x 是数学书，J(x)：x 是教材，“除了数学书，桌上的书都是教材”写作

\forall x((T(x)\wedge\neg M(x))\to J(x))

也可以把例外写进量词外层的否定：\neg\exists x(T(x)\wedge\neg M(x)\wedge\neg J(x))，与例1 第 (3) 题的两种写法同一个做法。

“除了”在中文里还有“除…以外还有”的读法（数学书也算教材之一）。动笔前先定读法：“其余都”把例外排除，“还有”改成合取。

把翻错的式子改回来

课件 2.3 例2 第 (2) 题“有些运动员不钦佩教练”，一个错写是这样的（L(x)：x 是运动员，J(y)：y 是教练，A(x,y)：x 钦佩 y）：

\exists x(L(x)\wedge\forall y(J(y)\wedge\neg A(x,y)))

逐处对：\exists x 在最外层，对；L(x) 作合取项，对；错在 \forall y 后面接了合取。\forall y(J(y)\wedge\neg A(x,y)) 要求每个客体都既是教练又不被 x 钦佩，一块石头代进去就不成立，整句随之变假。原句要的只是“存在一个教练没有被这位运动员钦佩”。

改回来：

\exists x(L(x)\wedge\forall y(J(y)\to\neg A(x,y)))

三处并排看：\forall y 的辖域只跨到它后面那对括号，A(x,y) 里的 x 因此仍是自由的（它归最外层的 \exists x 管）；存在接合取、全称接蕴含；\neg 只否 A(x,y) 这个原子公式。三处各过一遍，式子才唯一。

图的性质就是一句话

贯穿项目是关系与图算法工具包。第七章写成定义的那些图的性质，原型都是本课这种一句话的翻译。设论域为全体顶点，E(x,y)：x 与 y 之间有一条边：

  • 每点都连到某点：\forall x\exists y\,E(x,y)；
  • 存在孤立点：\exists x\forall y\neg E(x,y)。

第二句的 \neg 落在 \forall y 的辖域里面，读作“对每个 y 都没有边”；写成 \neg\exists x\forall y\,E(x,y) 就换了意思，那是“并非每点都连到所有点”。两句只差量词顺序与否定号的位置，判据还是辖域。

同一套写法在第三篇还会回来：二元关系的自反、对称，各是一句带量词的公式。现在把辖域与自由变元看清楚，那一篇只剩代入。
