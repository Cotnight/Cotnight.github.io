离散数学 Resources

定位：延伸阅读 + 易变内容的核对来源，不是"知识来源清单"（模型已掌握稳定基础知识）。
稳定知识节点可以不在这里留条目；易变/版本相关内容必须在这里有核对过的官方来源。

本科目盘问结论（决定本清单的取舍）：学生本学期正在修，教材是左孝凌《离散数学》（纸书，无电子版）；目标是期末考好 + 当逻辑与图论的长期底座（后续考研专业课可能用到）；要能独立使用（自然语言推理符号化并判有效性、真实场景抽象成图并算出来）；起点是跟课学过但不成体系、证明题无从下手；前置四项（集合与映射 / 命题逻辑与真值表 / 排列组合与数学归纳法 / 图的基本概念）自评"基本都忘了"，按"需要先唤醒"处理。
明确不学：数理逻辑元理论（完备性、紧致性、哥德尔）、高级组合计数（如波利亚计数）、超出考试要求的抽象代数专题。
配套项目（会变成实验课）：关系与图算法工具包（传递闭包 / 等价类划分 / 最短路 / 最小生成树），用教材例题反向验证，载体 Python 3.13；时间弹性、与数字电路共用同一份时间（数字电路优先）。
因此本清单的权重是：① 与学生纸书章号对得上的入口 ② 能真正把"证明怎么写"教会的方法论 ③ 关系/图与 Python 实验的官方文档 ④ 能当"往年卷子"用的题。本次没有提供本地资料路径、也没有可用的转换工具，且盘上还没有 reference/*.md，所以本清单不含 reference/ 指针——主教练若把课件/讲义转换落盘了，请在这里补一条 [Local: …](reference/…)。

二、专项补齐"证明题无从下手"

  • Source: Book of Proof（第 3 版，Richard Hammack，作者官方免费 PDF）· 含逐节目录 · PDF 直链 <https://richardhammack.github.io/BookOfProof/Main.pdf> · 已落盘 sources/book-of-proof-3e-toc.md
    一行说明：专门教"证明的写法"的整本书，被美国数学研究所（AIM）Open Textbook Initiative 收录，作者免费发 PDF（CC BY-NC-ND）。结构正对学生这条路径：第 2 章 Logic（2.9 把英文翻成符号逻辑、2.11 逻辑推理）→ 第 4 章直接证明、5 章逆否、6 章反证、7 章充要条件与存在唯一性、8 章集合相关的证明（证 a∈A、A⊆B、A=B）、9 章反驳（举反例）、10 章归纳法、11 章关系（11.3 等价关系 / 11.4 等价类与划分——对左版 3-10）、14 章基数（对左版 4-4～4-6）。用途：当"要写证明但不知道第一句该写什么"时，按它的章序练；它是英文的，只在学生愿意读英文时整章用，否则只挑 8.1～8.3（证集合相等）这类短节对照。
  • Book: Mathematics for Computer Science（Eric Lehman / F. Thomson Leighton / Albert R. Meyer，MIT 6.042 课程的免费公开教材，PDF）
    一行说明：MIT 计算机专业数学基础课的整本官方教材，免费公开，风格与罗森、屈婉玲都不同（更像"从证明与反例出发"）。用途：给"逻辑与图论当长期底座"这条要求提供第二个权威视角，也是考研专业课参考书的常见风格；证明写得磕磕绊绊时换它读同一主题。注意：本机抓取工具不支持 application/pdf，这本书的正文没有落盘，只能在线看或学生自己下载（已核实该 URL 返回的是 PDF）。

四、易变内容的官方核对来源（Python 3.13 / NetworkX）

这一节对应配套项目"关系与图算法工具包"。数学结论不会变，会变的是 Python 与库的 API，所以下面每条都指明核对哪一处版本差异。

  • Source: Python 3.13 标准库 graphlib — TopologicalSorter（官方文档） · 已落盘 sources/python-313-graphlib.md
    一行说明：实验课的第一块砖可以不装任何东西——标准库自带拓扑排序/环检测（TopologicalSorter、CycleError，自 3.9 起提供）。用途：把"偏序关系 → 哈塞图 → 拓扑排序"和"关系的闭包 → DAG"这两条线落到可运行代码上；文档原文那句 "a complete topological ordering is possible if and only if the graph has no directed cycles" 正好是可以让学生反向验证的教材级结论。核对点：学生本机是 Python 3.13（本页为 3.13.16 文档），请按 docs.python.org/3.13/ 而不是 /3/ 取文档。
  • Doc: Python 3.13 "What's New"（官方版本变更说明）
    一行说明：核对版本差异专用。用途：实验课代码要长期用，凡是从网上抄的片段，先在这一页确认它在 3.13 上还能跑（3.12 起 distutils 已移除、若干"最后警告"的模块在 3.13 被移除，旧教程里的写法会直接 ImportError）。也是"标准库现在推荐怎么写"的唯一权威出口。
  • Doc: NetworkX 3.7 官方文档 · Algorithms 索引
    一行说明：配套项目和"用教材例题反向验证"这件事的对照答案来源。可直接查到的当前 API：networkx.algorithms.dag.transitive_closure（传递闭包，对左版 3-8）、networkx.algorithms.minors.equivalence_classes（等价类，对 3-10）、algorithms.shortest_paths（最短路，对屈婉玲 6.3／罗森 6.6；左版无独立小节）、algorithms.tree.mst（最小生成树，对左版 7-7／罗森 7.5）、algorithms.dag.topological_sort（对偏序）。核对点：文档站默认跟 stable（当前 3.7），与 2.x 相比函数位置与参数有变动（例如 transitive_closure 在 dag 下、equivalence_classes 挂在 minors 下），照 2.x 博客抄会报错。
  • Doc: NetworkX 官方安装页
    一行说明：先核对再决定用不用。本角色不装任何东西、也不改环境，而本机是否能 import networkx 无法核实（本会话 shell 不可用，见 Gaps）；因此实验课默认走标准库（graphlib + 邻接表 dict + heapq 手写 Dijkstra + 三行 Warshall + 并查集），networkx 只当"对照答案"的可选依赖。要装的话按这一页的官方命令，由学生/主教练决定。

Wisdom (Communities)

  • 本科目未收录任何社区。中文离散数学的讨论主要散在文库类、问答站与聚合站，按本角色规则（低质量博客、聚合站、AI 生成内容不进清单）一律不收；学生目前也不需要"求批改"的渠道——批改由 practice-evaluator 做。原因另记在下方 Gaps。

Gaps

  • 左孝凌版没有官方配套习题解答。出版社（上海科学技术文献出版社）侧查不到任何配套资源页，市面上流传的"左孝凌《离散数学》课后习题答案"基本是文库站/聚合站转贴（含大量疑似 AI 生成或公式错位的稿子），按规则不进清单。替代方案：中国大学 MOOC 那门课的课后"计算、证明题"+ 南邮那套按章作业与答案 + 罗森第 1.7/1.8 章末练习（奇数编号答案在华章网站）。若后面确有需要，请主教练决定是否允许学生拍照纸书习题交给讲解角色处理——那是唯一不依赖外部来源的路。
  • 学生本校的教学大纲/考试范围没拿到，而这直接决定"学哪些、不学哪些"：左版第五篇（第八章形式语言与自动机、第九章纠错码初步）与第五章 5-6（置换群与伯恩赛德定理）是否在考纲内无法判断。南邮那份大纲按第 1～7 章组织（无第八、九章），只能当旁证。建议主教练第一节课就让学生拍自己的教学大纲或课程表。
  • 前置四项（集合与映射 / 命题逻辑与真值表 / 排列组合与数学归纳法 / 图的基本概念）没有"针对这门课的一次性唤醒"材料。各平台上的都是整门课（高等数学、线性代数）或整本教材，不是"离散数学用得到的那几条结论"的速查。本清单不为它凑条目——这一块属于稳定知识，建议由讲解角色内部产出"四张速查卡"（映射的满/单、真值表与常见等值式、两个计数原理与归纳法模板、图的基本术语）；英文对照可挑 Book of Proof 第 1～3 章。
  • 左孝凌那本书没有电子版，教材正文仍以纸书为准（本角色按规格只在"总控给了本地资料路径 + 转换工具"时才产 reference/，这次两者都没给到）。我在盘上看到 .stage/ppt-convert/ 下有两份 PPTX（k1.pptx、k2.pptx）和一个抽取脚本 extract_pptx.py，该转换已由主教练完成并入库（见上面两条 [Local: …]）；后续如需再补课件，请在这里补 [Local: …](reference/…) 条目并把用途写上（是讲义就写"确认老师讲到哪一节"，是答案就别当教材引用）。否则本科目所有章节引用只能以学生纸书的页码/节号为准，讲解要用原文时得由学生拍照。
