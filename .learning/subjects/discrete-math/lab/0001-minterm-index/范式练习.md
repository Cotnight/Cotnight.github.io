| 110 | 6 | P∧Q∧¬R | ¬P∨¬Q∨R |
| 111 | 7 | P∧Q∧R | ¬P∨¬Q∨¬R |

表的读法只有一条：**编号就是取值拼出来的二进制数**（真记 1）。大项不用另记：同一行上它是假的，编号与小项同号。

**公式怎么写**（`normal_form.py` 开头也有这张表）

```python

('not', 'P')            # ¬P
('and', 'P', 'Q')       # P∧Q
('or', 'P', 'Q')        # P∨Q
('imp', 'P', 'Q')       # P→Q
('nand', 'P', 'Q')      # P↑Q
('nor', 'P', 'Q')       # P↓Q
('T',) / ('F',)         # 1 / 0
```

例如 (P∧Q)↑R 写作 `('nand', ('and', 'P', 'Q'), 'R')`。

## 第 1 步 · 真值列与两组编号

**这一小步在讲什么。** 主析取范式就是"成真赋值清单"：把 2^n 行逐行求真值，真值为 1 的行记编号写
m，真值为 0 的行记同一个编号写 M。编号一个不漏，两组合起来正好占满 0～2^n-1。

**现在做。** 填 `normal_form.py` 的三个函数：

- `truth_vector(f, nvars)`：真值列，`'0'/'1'` 串，第 i 个字符是编号 i 那一行。
- `minterms(f, nvars)`：真值 1 的行号，升序 —— 就是 Σm。
- `maxterms(f, nvars)`：真值 0 的行号，升序 —— 就是 ΠM。

`assignments`、`env_of`、`evaluate` 都是现成的，按编号顺序排好直接求值即可。

**要点。**

- 第 i 项赋值就是 `bits(i, nvars)` 拆开的，顺序别自己另排。
- 别用代数展开算编号：展开时缺变元的支要一支补成两支，重合处最容易漏。
- 写完先用互补自查：同一式子的 Σm 与 ΠM 合起来必须正好 8 个编号。

1. `assignments(3)` 的第 5 项是哪个取值？它对应编号几？
2. 一个式子的 Σm 有 5 个编号，ΠM 该有几个？

**怎么算过。** `python -m unittest -v test_normal_form.TestTable`

这一节用的五个式子和它们的答案（断言里就是这个）：

| 式子 | Σm | ΠM |
| --- | --- | --- |
| (P→Q)∧(Q→R) | 0,1,3,7 | 2,4,5,6 |
| P→Q | 0,1,2,3,6,7 | 4,5 |
| ((P∨Q)→R)→P | 2,4,5,6,7 | 0,1,3 |
| (P→Q)∧(P→R) | 0,1,2,3,7 | 4,5,6 |
| P∨(Q→R) | 0,1,3,4,5,6,7 | 2 |

抽查一行：`(P→Q)∧(Q→R)` 在 010（P=0、Q=1、R=0）上，P→Q 真、Q→R 假，合取为假，
所以 010 这一行进 ΠM，不进退 Σm。

## 第 2 步 · 缺变元的项要补成小项

**这一小步在讲什么。** 一个乘积项缺 k 个变元，缺的那些取 0 取 1 都不改变它，于是它落 2^k 格。
`Q∧R` 在三变元里缺 P，落 m3（P=0）与 m7（P=1）两格，不是一格。

**现在做。** 填 `expand_term(term, nvars)`：`term` 写成 `{'Q': 1, 'R': 1}` 这样的部分赋值，
返回编号列表（升序）。最省事的写法是把 0～2^n-1 全试一遍，满足 term 里每一条约束的都算。

**要点。**

- 缺变元数决定**落几格**，剩下的决定**落在哪几格** —— 两件事都要对。
- 一个都不缺就只落 1 格；三个都不定就落满 8 格。
- 三支补完要逐支列出来再看并集，别直接并成一组 —— 重合就看不见了。

**卡在这里就问自己两句。**

1. `{'P': 0, 'R': 1}` 缺哪个变元？它该落几个编号？
2. 编号 101 满足 `{'P': 0, 'R': 1}` 吗？

**怎么算过。** `python -m unittest -v test_normal_form.TestExpand`

`(P→Q)∧(Q→R)` 代数展开后剩三支，每支的补法：

| 支 | 缺的变元 | 补成的小项 |
| --- | --- | --- |
| ¬P∧¬Q | R | m0、m1 |
| ¬P∧R | Q | m1、m3 |
| Q∧R | P | m3、m7 |

三支一共写出 6 个编号，并起来只有 4 个：**m1 与 m3 各出现两次**。并集是 Σm(0,1,3,7)，
取补得 ΠM(2,4,5,6) —— 与第 1 步真值表算出来的同一组，这就是互相盖章。

## 第 3 步 · 对偶式要换三组符号

**这一小步在讲什么。** 对偶不是"把 ∧ 换成 ∨"就完事：∧↔∨、↑↔↓、1↔0 三组一起换，
变元、括号、否定号一概不动。漏掉 ↑↔↓ 那一组，写出来的是另一个公式，而且它照样能算到底。

**现在做。** 填 `dual(f)`：递归下去，`'and'` 与 `'or'` 互换，`'nand'` 与 `'nor'` 互换，
`('T',)` 与 `('F',)` 互换；`'not'` 与变元原样返回。

**要点。**

- 三组一起换：只换第一组是最常见的错。
- 取两次对偶要回到原式 —— 但这条自查对"只换一半"**不设防**，别只靠它。
- 可靠的验法是折成 ¬、∧、∨ 再取对偶，两条路结果必须一致。

**卡在这里就问自己两句。**

1. `(P∧Q)↑R` 里的 ↑ 换完该是哪个符号？
2. 折成 ¬ 之后这个式子是什么？它的对偶又是什么？

**怎么算过。** `python -m unittest -v test_normal_form.TestDual`

三条例题（断言里逐条比）：

| 原式 | 对偶式 |
| --- | --- |
| (P∧Q)↑R | (P∨Q)↓R |
| ¬P∨(Q∧R) | ¬P∧(Q∨R) |
| (P∧Q)∧1 | (P∨Q)∨0 |

## 第 4 步 · 否号推到底，再判等值

**这一小步在讲什么。** 否号要一路推到变元前面，穿过括号时 ∧ 与 ∨ 必须互换 ——
¬(P∨Q) 是 ¬P∧¬Q，不是 ¬P∨¬Q。判等值则是另一件事：两个式子按**同一组变元**各求编号表，
逐行相同才叫等值。

**现在做。** 填两个函数：

- `to_nnf(f)`：只留 ¬、∧、∨，否定号都贴在变元上。写法是带一个"当前在不在否号底下来"的标记递归；
  顺手把 →、↑、↓ 消掉（`A→B` 换成 `¬A∨B`，`A↑B` 换成 `¬(A∧B)`，`A↓B` 换成 `¬(A∨B)`）。
- `same_function(f, g)`：两个式子的变元取并集，n 取到最靠后的那个变元为止，再逐行比真值列。

**要点。**

- 否号穿进 ∧ 变 ∨，穿进 ∨ 变 ∧；穿两次回到原样。
- 判等值时两边必须用同一个 n：各按自己出现的变元算一次，编号就错位了。
- `P→Q` 与 `¬P∨Q` 等值；`(P→Q)∧(Q→R)` 与 `P→R` **不**等值，前者只是蕴含后者。

## 第 5 步 · 把三处错法顶出来
