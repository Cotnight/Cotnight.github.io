# 数字电路 Resources

> 定位：**延伸阅读 + 易变内容的核对来源**，不是"知识来源清单"（模型已掌握稳定基础知识）。
> 稳定知识节点可以不在这里留条目；易变/版本相关内容必须在这里有核对过的官方来源。
>
> 本科目盘问结论（决定本清单的取舍）：**本学期在修 + 期末考好 + 为考研打底**，程度到「看见功能要求能自己判断用组合还是时序、能搭出来并说清为什么」，**不要 HDL／FPGA、不要模电本体（放大电路／运放）、不要 CMOS 版图与半导体工艺、不要 TTL／CMOS 门内部逐管电路**。
> 两个真实卡点：**① 真值表 → 卡诺图 → 最简式**（组合逻辑）；**② 触发器/计数器没底**（时序逻辑）。清单因此把权重压在「康华光对应章节的官方目录 + 组合/时序/状态机三段讲法 + 数字钟要用到的器件功能表」上。
> 载体是**本机 Python 3.13 仿真**（断言校验波形与真值表），**不装新工具链**——所以没有任何 Logisim／Verilog／EDA 条目。
> 学生手上有**康华光《电子技术基础·数字部分》纸书**（无电子版），**没有本地资料**——因此**本清单没有 `reference/` 指针条目**，教材正文一律以纸书为准。

## Gaps

- **教材版次未确认，且学生没有电子版**。盘问只记到“康华光《电子技术基础·数字部分》”，**没记第几版、哪一年印**；而第 6 版与第 7 版的节号、附录、章节构成都有差异（对照表已落 `sources/hep-kanghuaguang-toc-6e-7e.md`）。**影响**：大纲与课件里报“第 X 章第 Y 节”存在错位风险。**建议**：第一次讲课时请学生翻纸书目录报一次版次/印次，之后固定用那一版的节号。**没有电子版**＝本科目 `reference/` 为空（第 0 步无可转换的本地资料，故未派转换子 agent），教材正文只能由模型按知识讲、用官方目录对章节号。
- **考研方向没有权威的“统一大纲”可引**。数字电路在多数院校是**招生单位自命题**（不像 408 有统考大纲），同一科目各校参考书与考纲差别很大。本清单只能给到“考研题型组织”的公开辅导书（王淑娟、蔡惟铮那本）。**缺什么**：目标院校当年的自命题科目考试大纲与参考书目。**怎么补**：需学生给出目标院校/专业，从该院校研究生院官网取当年公告（每校每年更新、URL 不稳定，因此不入清单）。
- **GB/T 4728.12—2008 全文不可免费获取**。国家数字标准馆只有记录页，推荐性国标全文公开系统未收该部分；网上流传的 PDF 来源不可信。**结论**：逻辑符号一律以学生纸书附录 A/B 为准，不要在这一项上找公开全文。
- **TI 数据表正文抓不动**。`ti.com/document-viewer` 的**分节正文是前端渲染**，抓取只返回整份目录（本次确认：SN74HC138、NE555 均只得 TOC）；`ti.com/lit/...pdf` 直接返回 `application/pdf`，本会话取不了。**影响**：`sources/` 里没有器件功能表原文，只有链接；讲功能表时凭模型知识 + 学生可自行点开的小节锚点。**下游提醒**：`image-scout` 不要指望从 ti.com 抓图（需 JS），要引脚图请另找可静态抓取的官方页。
- **OCW 6.004 的章节正文页抓不到**。`c4`/`c5`/`c6` 页与 `syllabus` 页都只回导航树 + 课程信息，讲义是 PDF、视频在站内。本次只确认了**章标题与章节结构**，没核实过任何一页的具体讲法。
- **两个中文 MOOC 平台（国家高等教育智慧教育平台、icourse163）课程页的章节列表抓不到**（前端渲染，返回空壳）。条目只能当“入口”用，无法做“第几讲对应第几节”的精确映射；需要精确对应时必须人工点开看。
- **没有找到可推荐的活跃中文学生社区**。中文讨论集中在文库类与问答站（聚合站、AI 生成内容按本角色规则一律不入清单），知乎类站点抓取受限。**结论**：Wisdom 只给了一条英文 Stack Exchange；“求批改作业”这个需求目前只能由 system 内部的练习评估承担。
- **没有公开的“期末往年卷”来源**。本次检索未找到与康华光教材配套、可长期访问的期末真题/模拟卷（校内流传卷与商业题库不在高可信范围内，未收）。**影响**：`MISSION.md` 里“期末卷上组合逻辑、时序逻辑两类题不丢分”这一条，无法靠外部卷子校准难度。**建议**：由 `practice-evaluator` 按教材题型自建练习，覆盖度靠课本习题 + 两本官方题解反推（已在上面 Knowledge 里给了入口）。
