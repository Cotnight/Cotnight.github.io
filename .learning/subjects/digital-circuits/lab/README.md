# 实验与上手练习

这里是数字钟这门课的所有 lab。一节 lab 一个子目录，参考解放在 `solutions/` 下的同名子目录里。

## 载体与环境

- Python 3.13，只用标准库 `unittest`。
- 不装任何第三方包，不要编译工具链，不联网。
- 卡诺图一律用文本画（等宽表格对齐）：填错一格肉眼能对，断言能逐格报出来。
  本课的图都是格表，不需要图片，也不需要绘图库。
- 本机解释器：`D:/Program Files/Python313/python.exe`
  （PowerShell 里 `py -3` 一般也指向它；以能跑起来的那一个为准。）

## 怎么跑

在某一节 lab 的目录里跑：

```sh
cd lab/0001-kmap-fill
python -m unittest -v test_kmap
```

只跑一组：

```sh
python -m unittest -v test_kmap.TestBroken
```

`subTest` 会把失败的每一格单独列出来，例如 `取值='011' m='m3'` —— 那就是「取值 011，最小项 m3」
那一格没对上。

## 卡壳顺序

1. 先读断言报的那一格：`subTest` 里的 `m` 编号就是格号，把它写成取值串，回图上找一眼。
2. 还连不上就查两处：两条轴的标号是不是 `00 01 11 10`；缺变量的项是不是落了 `2**k` 格。
