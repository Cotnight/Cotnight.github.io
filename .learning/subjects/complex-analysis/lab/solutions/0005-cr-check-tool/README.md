# 参考解 · 0002-cr-check-tool

`cr_tool.py` 是这一课 lab 的参考解：把它拷进 `lab/0002-cr-check-tool/` 覆盖同名文件，
`python test_cr_tool.py` 就是 22 个测试全绿（实测 `Ran 22 tests … OK`）。

**先自己做到全绿，再对照这里。** 下面按步写"参考解为什么这样写"和"最常见的错法"。

## 九步要点

| 步 | 参考解的做法 | 最常见的错法 |
|---|---|---|
| 1 `d_dy` | 步进 `1j*h`，分母 `2*h` | 分母写成 `2*h*1j`——对 $z^2$ 会算出 $f'(z)$ 而不是 $i f'(z)$ |
| 2 `cr_residual` | `d_dx` 的实部是 $u_x$、虚部是 $v_x$；`d_dy` 的实部是 $u_y$、虚部是 $v_y$ | 把 $v_x$ 当成 $v_y$；$r_2$ 写成 $u_y-v_x$（差一个负号） |
| 3 `cr_holds` | 两条残差都 `abs(...) <= tol` | 用 `== 0` 判等——浮点差分永远差一点点 |
| 4 `cr_points` | 列表推导，保持传入顺序 | 用 `set`（顺序乱、还丢了重复点） |
| 5 `verdict` | 先判空返回 `'none'`，再比命中个数 | 忘了空列表；`all([])` 在 Python 里是 `True`，会被判成 `'all'` |
| 6 `laplacian` | $(u(z{+}h)-2u+u(z{-}h))/h^2$ 加上 $ih$ 那一份，用 `DEFAULT_H2` | 用 `DEFAULT_H`（$10^{-6}$）——除以 $h^2$ 后舍入误差放大到 $10^{-3}$，看着像"不调和" |
| 7 `is_harmonic` | 每个点 `abs(laplacian) <= tol` | 只看平均值或只看一个点 |
| 8 `polar_cr_residual` | $w(r,\theta)=f(r e^{i\theta})$，对 $r$、$\theta$ 各做中心差分，再除 $1/r$ | 漏掉 $1/r$（残差差常数倍：$z^2$ 在 $r=2,\theta=0.4$ 处会算出 $-2.79$ 而不是 0） |
| 9 整表自检 | 不用写，跑 `-k step9` | — |

## 两个"数值做法才有的"判断

- **容差**：纸上写 $u_x=v_y$ 是恒等式，代码里是近似相等，所以每一步都要带 `tol`。
  这也是为什么 `cr_holds` 的参数里有 `tol`——它对应卷面上"条件成立的点集"这个说法。
- **步长**：一阶差分 $h=10^{-6}$ 最好（截断误差 $O(h^2)$ 与舍入误差 $O(\epsilon/h)$ 折中）；
  二阶差分要除以 $h^2$，步长得放大到 $10^{-4}$。同一套代码里给两个默认值就是这个原因。
