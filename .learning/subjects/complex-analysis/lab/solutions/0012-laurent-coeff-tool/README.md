# 参考解 · 0012-laurent-coeff-tool

`laurent_tool.py` 是这一课 lab 的参考解：把它拷进 `lab/0012-laurent-coeff-tool/` 覆盖同名文件，
`python test_laurent_tool.py` 就是 29 个测试全绿（实测 `Ran 29 tests … OK`，退出码 0）。

**先自己做到全绿，再对照这里。** 下面按步写"参考解为什么这样写"和"最常见的错法"，
错法后面括号里是实测会得到的数，对着断言看就知道自己卡在哪。

## 九步要点

| 步 | 参考解的做法 | 最常见的错法（实测值） |
|---|---|---|
| 1 `contour_points` | `center + radius·e^{iθ}`，θ = 2πk/n | 忘了乘 `radius`——点全落在圆心，第 2 步直接 `ZeroDivisionError`；角度写成 $-2πk/n$，整圈顺时针，所有系数变号（$c_0$ 得 $-0.5$） |
| 2 `coeff_integral` | $dz$ 换成 $i\,Δθ\,(ζ-center)$，n 项相加后除以 `TAU_I` | $dz$ 只写 $Δθ$（$c_1$ 得 `0.0`，全为 0）；漏掉 $(ζ-center)$（$c_0$ 得 `0.75`、$c_1$ 得 `0.875`，正确是 `0.5`、`0.75`）；分母用 $2π$ 而不是 $2πi$（结果整体转 $90°$，$c_0$ 得 `0.5j`） |
| 3 `coeffs` | `{k: coeff_integral(f, k, center, radius, n) for k in ks}` | 半径给错（把 1.5 的环域用 0.5 去算，负幂项全变 0）；顺手改了默认 `n` |
| 4 `series_value` | `sum(c * (z - center) ** k, 0j)` | 空表返回 `None`（`TypeError`）；负幂自己写成 `1/(z-center)**(-k)`，符号与指数错位 |
| 5 `truncation_error` | `abs(series_value(...) - f(z))` | 忘了 `abs`，拿到复数，`assertLess` 直接报类型错；或者两条环域的系数混着用（误差停在 $1$ 量级） |
| 6 `partial_fractions` | $A=1/(a-b)$、$B=1/(b-a)$（遮住因式、把根代进去） | 两个权重对调（拆开前后差一个符号，三点恒等式全红）；漏掉负号（$z=0.3$ 处差 `1.68`） |
| 7 `geom_coeffs` | `inside`：$c_n=-a^{-(n+1)}$；否则 $c_{-n-1}=a^n$ | 两支写反（第 8 步三个环域全串）；`outside` 支漏了 $1/z$，指数整体差一位 |
| 8 `ring_coeffs` | 先按 $\lvert a\rvert$、$\lvert b\rvert$ 排谁近谁远，再逐项取分支、乘权重、同幂**相加** | 假设 `a` 更近（`ring_coeffs(2, 1, ...)` 立刻错）；同幂次写成 `out[k] = ...` 覆盖（`outer` 的 $c_{-3}$ 得 `-1` 或 `4`，正确是 `3`） |
| 9 整表自检 | 不用写，跑 `-k step9` | — |

## 两个"数值做法才有"的判断

- **采样点数不是随心写的**。梯形法在圆周上的误差按 $(d/r)^n$ 掉，$d$ 是离圆心最近的奇点距离。
  中间环域 $1<\lvert z\rvert<2$ 取 $r=1.5$、$d=1$，实测 $c_1$ 的误差：$n=16$ 是 $4.1\times10^{-3}$、
  $n=32$ 是 $2.7\times10^{-5}$、$n=64$ 是 $2.5\times10^{-9}$、$n=128$ 已经到 $10^{-16}$。
  默认 `DEFAULT_N = 512` 留了余量；你要是把它改成 32，看到的是**采样不够**，不是纸面算错。
- **容差 1e-8 是给浮点的，不是给推导的**。"系数等于纸面公式"在代码里是近似相等，
  所以每一步都用容差比；而截断误差那一组按项数给上限：$e^z$ 取到 $n=2$ 时误差 $2.2\times10^{-1}$、
  $n=5$ 时 $1.6\times10^{-3}$、$n=8$ 时 $3.1\times10^{-6}$、$n=11$ 时 $2.3\times10^{-9}$。

## 第 8 步为什么必须"先排序"

参考解先 `near, far = sorted((a, b), key=abs)`，再用 `ring` 决定谁落在圆内。
写成"`a` 提常数、`b` 提 $1/z$"也能过 `(1, 2)` 这几条断言，但一传 `(2, 1)` 就错——
`test_step8_middle` 专门用 `ring_coeffs(2, 1, 'middle', 5)` 对了一遍，就是抓这个。

## 第 9 步那两张表在验什么

- 课件那三条展开（$\lvert z\rvert<1$、$1<\lvert z\rvert<2$、$\lvert z\rvert>2$）的系数按纸面公式现写在测试里，
  与围道积分逐个比——这张表绿了，说明你的工具和课件那张图对得上；
- 合肥工大卷那道 10 分题 $f(z)=\frac{z+1}{(z-1)^2}$ 的两问：$0<\lvert z\rvert<1$ 里 $c_0=1$、$c_n=2n+1$；
  $\lvert z\rvert>1$ 里 $c_{-1}=1$、$c_{-m}=2m-1$。考场上有这层保险，抄串环域这种错当场就能发现。

## 做完了能拿走什么

- `ring_coeffs` 就是卷面那四步（定环域 → 拆部分分式 → 凑几何级数 → 合并系数）的代码版，
  写错哪一步，哪一档系数就对不上；
- `coeff_integral(f, -1, z0, r)` 直接给 $c_{-1}$——第 14 课（留数）要的就是这一个数；
- `contour_points` 到实验四（围道上的留数）还要用：围道怎么采点、极点画在哪，这一节已经给了。
