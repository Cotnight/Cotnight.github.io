# 参考解 · 0015-contour-residue

`contour_residue.py` 是实验四（围道上的留数）的参考解：把它拷进
`lab/0015-contour-residue/` 覆盖同名文件，`python test_contour_residue.py` 就是 48 个测试全绿
（实测 `Ran 48 tests in 0.033s … OK`，退出码 0）。

**先自己做到全绿，再对照这里。** 下面按步写「参考解为什么这样写」和「最常见的错法」。

## 十步要点

| 步 | 参考解的做法 | 最常见的错法 |
|---|---|---|
| 1 `nth_roots` | `|z0|**(1/n)` 乘 `exp(1j*(theta0+2πk)/n)`，`range(n)` | 中途 `math.degrees` 一下再塞回公式（角度制混进弧度式，整块面板转错角） |
| 2 `segment_points` | `a + (b-a)*k/(n-1)`，`range(n)` | 参数写 `k/n`，线段终点永远差一截；`n < 2` 时不抛 `ValueError` |
| 3 `circle_contour` | `center + radius*exp(1j*2πk/n)`，`range(n)` | 忘了乘 `radius`（点全在圆心）；角度加负号变顺时针 |
| 4 `contour_integral` | 循环 `f(z) * 1j*dtheta*(z-center)` 累加 | 漏 `1j`（得 $2\pi$ 实数）；漏 `(z-center)`（常数被积函数得 $2\pi i$） |
| 5 `inside` | `abs(z0-center) < radius` | 写 `abs(z0) < radius`（圆心一挪就数错）；写成 `<=`（把压在围道上的点算进圈内） |
| 6 `residue_theorem` | `TAU * sum(res for z0,res in poles if inside(...))` | 漏乘 `TAU`（得到的是留数之和）；把圈外的一起加进来 |
| 7 `ledger_row` | 四个数各调一次前面几步，`gap` 取模、`verdict` 按 `TOL_AGREE` 切 | `enclosed` 写成 `len(poles)`（S3、S4 就分不出来了） |
| 8 `save_contour_csv` | 先围道点后奇点，`mark` 用第 5 步判 | `open` 少了 `newline=""`（每行变两行）；四位小数把相邻两点写成同一个数 |
| 9 `write_gallery` | 四行照抄同一形状，行数由 `write_csv` 返回 | 行数手写死（改一个常数就全错）；面板名或文件名写错，测试按名字找文件 |
| 10 `ascii_canvas` | 先取包围盒，再落格，行号 `height-1-...` 翻过来 | 忘了翻行（图上下颠倒）；先画极点再画围道（`*` 被 `.` 盖掉） |

## 容差为什么定成 `TOL_AGREE = 1e-6`

围道上的 `dz` 取的是解析式 $i\,\Delta\theta\,(z-a)$，不是折线的 $\Delta z$，所以梯形法对圆周上的
被积函数是**指数收敛**的：$n=2048$ 时误差早到机器精度。参考解实测的四条（`gap` 是
$\lvert$数值$-$定理值$\rvert$）：

| 案 | 圈内奇点 | 数值积分 | $2\pi i\sum$ 留数 | gap |
|---|---|---|---|---|
| S1 $1/((z+1)(z+2)^2)$ 沿 $\lvert z\rvert=3$ | 2 | $-1.96\times10^{-17}-2.05\times10^{-17}i$ | $0$ | $2.8\times10^{-17}$ |
| S2 $e^z/((z-\pi i)(z-2\pi i)^2)$ 沿 $\lvert z\rvert=8$ | 2 | $2+1.273239545i$ | $2+1.273239545i$ | $2.1\times10^{-14}$ |
| S3 同 S2 换成 $\lvert z\rvert=4$ | 1 | $0.6366197724i$ | $0.6366197724i$ | $1.5\times10^{-15}$ |
| S4 同 S2 换成 $\lvert z\rvert=2$ | 0 | $-5.6\times10^{-17}-1.2\times10^{-16}i$ | $0$ | $1.3\times10^{-16}$ |

四条都在 $10^{-14}$ 以下，所以 $10^{-6}$ 这个容差有一整个数量级以上的余量；它卡的是另一件事——
**少列一个奇点差的是 $2.1$ 这个量级**，不是 $10^{-6}$。容差定得越松，「漏了一个奇点」就越容易被
误判成「一致」。

## 两个对照：换围道、少列奇点

同一份被积函数 $e^z/((z-\pi i)(z-2\pi i)^2)$，只换围道半径，两边一起变：

| 围道 | 圈内 | 数值积分 | $2\pi i\sum$ | 结论 |
|---|---|---|---|---|
| $\lvert z\rvert=8$ | $\pi i$ 与 $2\pi i$ | $2+1.2732i$ | $2+1.2732i$ | 一致 |
| $\lvert z\rvert=4$ | 只剩 $\pi i$ | $0.6366i$ | $0.6366i$ | 一致 |
| $\lvert z\rvert=2$ | 一个都没有 | $\approx 0$ | $0$ | 一致 |

**变的是答案，不变的是等号。** 这就是留数定理的内容：右边跟着圈内的奇点走，左边自动跟上。

S5 换的是另一头——围道不动（还是 $\lvert z\rvert=8$），**故意只列一个奇点**：

| 列法 | $2\pi i\sum$ | 与数值积分（$2+1.2732i$）差 |
|---|---|---|
| 两个奇点都列（正确） | $2+1.2732i$ | $2.1\times10^{-14}$ |
| 只列 $\pi i$（S5） | $0.6366i$ | **$2.1$** |

数值围道积分站哪边，哪边就是对的——它就是这一课的裁判。卷面上「围道内有两个奇点只算一个」
那个失分点，在账本里就长得这个样子：一个数差了 $2.1$，量级一眼就能看出来。

## 字符画为什么是 41×21

终端一个字符格大约「宽 1、高 2」，所以圆的包围盒（正方形）落到 `width=41, height=21` 上才画得
像圆；按 45×17 画出来是压扁的椭圆。`ART_N = 180` 是每圈采点数：41 列上每列正好落 4~5 个点，
上缘与下缘不会出现断口（96 点时上缘是 `.. .. ... ..` 那样的虚线段）。

`out/panel4-contour.csv` 与字符画读的是**同一批数**：前者是坐标，后者是把坐标落到格子上。

## 做完能拿走什么

- 四块面板落在同一份 `out/` 里（5 + 25 + 24 + 182 行），前三个实验的图不必再翻旧目录；
- 一张账本 `out/ledger.csv`：每条围道一行，数值积分与 $2\pi i\sum$ 并排放。这张表就是
  「留数定理验过了」的凭据，也是查错时最先该看的地方；
- 「围道—极点」那张图的数据（`out/panel4-contour.csv`）与不用 matplotlib 的字符画；
- 判据：`gap <= 1e-6` 才算一致；凑不上时先数圈内奇点个数（`enclosed` 那一列），再查留数本身。
