# 参考解 · 0009-cauchy-formula-tool

`cauchy_tool.py` 是这一课 lab 的参考解：把它拷进 `lab/0009-cauchy-formula-tool/` 覆盖同名留白文件，
`python test_cauchy_tool.py` 就是 26 个测试全绿（实测 `Ran 26 tests … OK`，退出码 0）。

**先自己做到全绿，再对照这里。** 下面按步写「参考解为什么这样写」与「最常见的错法」。

## 九步要点

| 步 | 参考解的做法 | 最常见的错法 |
|---|---|---|
| 1 `circle_points` | $z_k=a+r\,e^{i2\pi k/n}$，$k=0..n-1$ | 忘了乘 `radius`（点全落在圆心）；角度写成负的（方向反了） |
| 2 `contour_integral` | 每项乘 `1j * dtheta * (z_k - center)` | $dz$ 漏 `1j`（$\oint dz/z$ 得实数 $2\pi$）；漏 `(z_k-center)`（常数积分不为 $0$） |
| 3 `inside` | `abs(z0 - center) < radius` | 写成 `<=`，把压在围道上的点也算进圈内 |
| 4 `deriv_n` | 0 阶返回 `g(z)`；1 阶用 $2h$，2 阶用 $h^2$，默认 `DEFAULT_H2` | 二阶用 `DEFAULT_H`（舍入误差被 $1/h^2$ 放大到 $10^{-3}$）；忘了 0 阶 |
| 5 `cauchy_value` | `TAU * g(z0)` | 在这里多求一次导；把 `2j*math.pi` 写成 `2*math.pi`（丢了 $i$） |
| 6 `high_order_value` | `TAU / factorial(m-1) * deriv_n(g, z0, m-1)` | 阶乘写 `m!`、求导写 `m` 阶（两处都得是 $m-1$）；三处混着用 |
| 7 `formula_value` | `m == 1` 走第 5 步，否则第 6 步 | 判断写成 `m > 1` 时第一支反了 |
| 8 `contour_total` | 遍历 `terms`，圈外的 `continue`，其余累加 | 只算一个奇点；$g$ 里还带着自己的极点（`ZeroDivisionError`） |
| 9 整表自检 | 不用写，跑 `-k step9` | — |

## 两个「数学上」的判断

- **每个奇点的 $g$ 都不一样**：$\frac{2z+1}{(z-1)(z+2)}$ 在 $z_0=1$ 处 $g=\frac{2z+1}{z+2}$，
  在 $z_0=-2$ 处 $g=\frac{2z+1}{z-1}$。写成「整个分子」会漏掉分母剩下的那个因子，
  更糟的是把 $g$ 写成原式本身——代入 $z_0$ 时 $0$ 做分母，直接 `ZeroDivisionError`。
  `terms` 里存的是「配方」，不是被积函数。
- **围道上不能有奇点**：$z_0$ 落在 $C$ 上时两条公式都不适用，数值积分也会发散。
  课件的 $\oint_{\lvert z\rvert=2}\frac{dz}{z^2-1}$ 是奇点 $\pm1$ 都在圈内，成立；
  但 $\frac{2z+1}{z^2+z-2}$ 的奇点 $-2$ 恰好压在 $\lvert z\rvert=2$ 上——所以那道真题的围道
  写的是 $\lvert z\rvert=3$。实测：同一个被积函数把围道换成 $\lvert z\rvert=2$，
  数值积分会炸到 $10^{13}$ 量级；`inside` 用严格小于，正是为了把这种点挡在外面。

## 三个「数值做法才有的」判断

- **采样点数 $n$**：梯形法对周期解析函数按 $(d/r)^n$ 收敛（$d$ 是奇点到圆心的距离）。
  $n=2048$ 时实测 $\oint_{\lvert z\rvert=2}\frac{dz}{z}=2\pi i$ 的误差是 $2\times10^{-13}$，
  六道真题的数值那一列误差都在 $2\times10^{-14}$ 以内。
- **求导步长 $h$**：一阶 $10^{-6}$、二阶 $10^{-4}$。二阶差分除以 $h^2$，$h$ 太小反而不准。
  参考解在 $m=3$、$g=\cos z$、$z_0=i$ 处，公式那一列与理论值 $-\pi i\cos i$ 相差 $2\times10^{-8}$
  ——**这是截断误差，不是算错**。容差 $10^{-6}$ 就是为它留的。
- **容差**：纯数值围道积分用 $10^{-9}$，含数值求导的公式值用 $10^{-6}$，
  「对数值积分再求一次导」（第 9 步反向读公式）用 $10^{-4}$。

## 做完了能拿走什么

- 一条**能自我校验**的公式：纸上算出 $\frac{2\pi i}{(m-1)!}g^{(m-1)}(z_0)$，代码里立刻能验；
- 幂次对照卡（$m=1,2,3,4$ ↔ 求几阶导 ↔ 系数）落成了 `formula_value` 的一个分支；
- 「围道内两个奇点拆开相加」落成了 `contour_total` 的一次遍历，少一项会被断言抓住；
- 第 13 课（留数定理）把每一项 $2\pi i\,g(z_0)$ 改叫「$2\pi i$ 乘留数」，
  `circle_points` 与 `contour_integral` 可以直接搬去画实验四的围道。
