怎么算过

被验收的那一课要求是「做出能画出方根分布与 z^2+c 迭代图的 Notebook」。把它拆成三条，逐条都有可观察的证据：

  1. 能跑：gallery.ipynb 从头 Run All 不报错。这是「做出 Notebook」的硬证据。
  2. 画得出：图里有东西——方根的 5 个点等距落在同一个圆周上；缩略图能看出边界，不是全黑、全白或上下颠倒。
  3. 算得对：python test_gallery.py 打出 OK（28 条断言，管方根的模与角、|z|>2 的严格判据、网格行序、CSV 格式）。

三档结论：

  • 通过：三条都成立，并且你能指着代码说出「哪一行让方根等距」「凭什么 |z|>2 就一定逃逸」。
  • 部分通过：图出来了但断言没全绿（数值有错）；或断言全绿但 notebook 跑不起来、图看不出结构。
  • 不通过：只填了函数没有 notebook，或者 notebook 里的图是空的、上下颠倒、只有一两个点。

上手做 第 3 步 · 写两句结论

结论 cell 只要两句话，别写小作文：

  1. n 个方根的模都等于 \sqrt[n]{|z_0|}、相邻夹角都是 360^\circ/n，所以连起来是正 n 边形。
  2. |z| 某一步一旦超过 2 就必然飞向无穷，所以「第几步超过 2」能把复平面染成一张有边界的图。

方根为什么成正多边形

你跳过的那一节里有个公式，这一课要用它，直接补在这儿。z_0\ne0 的 n 个 n 次方根是

z_k=\sqrt[n]{|z_0|}\;e^{i(\theta+2k\pi)/n},\qquad \theta=\operatorname{Arg} z_0,\quad k=0,1,\dots,n-1 .

两件事从式子里直接读出来：模都是 \sqrt[n]{|z_0|}，所以都在同一个圆上；相邻两个根的角度差是 2\pi/n，所以等角排开。圆 + 等角 = 正 n 边形，重心在原点——于是 n 个根加起来正好是 0。

拿 z_0=1+i、n=5 手算一遍：|z_0|=\sqrt2、\theta=45^\circ，所以模是 \sqrt[10]{2}\approx1.0718，五个角度依次是 9^\circ,81^\circ,153^\circ,225^\circ,297^\circ（每隔 72^\circ）。画出来就是这幅正五边形。

别用角度制算方根

cmath.phase 给的是弧度，cmath.exp 吃的也是弧度。中途转成度数再塞回公式，整张图会转错一个角度—— 测试第一条抓的就是这个数。

迭代图的边界怎么来

迭代规则只有一行：z\mapsto z^2+c。从 z_0=0 出发、让 c 跑遍平面，那些永不逃逸的 c 组成曼德博集；固定 c、让起点跑，得到朱利亚集。这一课做前者当缩略图。

为什么可以用「|z|>2」判逃逸：若某步 |z|>2 且 |z|\ge|c|，则

|z^2+c|\;\ge\;|z|^2-|c|\;\ge\;|z|\bigl(|z|-1\bigr)\;>\;|z| ,

模每一步都在涨，一定飞出去。反过来说，被抓住的点永远在 |z|\le2 的圈里。

颜色就是逃逸步数：越靠近边界，需要越多的步数才飞出去，颜色越亮；集内用迭代预算把它涂满。所以 max_iter 太小，边界会糊成一片、看不出分形结构——这是本课第二常见的坑。
