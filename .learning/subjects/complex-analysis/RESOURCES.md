# 复变函数与积分变换 Resources

> 定位：**延伸阅读 + 易变内容的核对来源**，不是"知识来源清单"（模型已掌握稳定基础知识）。
> 稳定知识节点可以不在这里留条目；易变/版本相关内容必须在这里有核对过的官方来源。
>
> 本科目盘问结论（决定本清单的取舍）：**应试定位**——只考前题型识别与计算熟练度，**不看定理证明**；
> **共形映射、数值方法一律不要**。学生**没有往年卷子、没有习题册**，手上只有第 1 章的四节课件。
> 因此本清单的权重偏向「考试怎么考 / 用哪条公式 / 典型题型长什么样」的入口，以及能补上"没题可做"的资源。

## Gaps

- **公开网页版「附录 B 常用积分变换表」找不到**。试过的方向：机工社官方页只给出附录页码（第 1 版 129 页 / 第 2 版 123 页）；高教社商城的《复变函数与积分变换（第五版）》**有**官方页面，但**目录与附录清单没有在页面上展开**（只有封面与商品信息）；清华云盘那份《常用公式（含 L 与 F 变换）》跨域被拦（403）、且需要授权，不算可长期访问的公开来源。**结论：附录 B 的核对请以学生纸质书为准**，本清单用同系列教材（陈丽娟版）的公开附录目录 + 南大 DSP 讲义做形状对照；不要在这一项上等公开速查页。
- **前置基础（多元微积分 / 级数收敛 / 线性代数 / 常微分方程）四项学生自评"学过但忘了"，没找到权威的"针对复变课的一次性唤醒"材料**。各校都有《高等数学》公开课，但那是**整门课**，不是"复变课用得上的那几条结论"的速查。本清单没有为它凑条目——**这一块建议在主教练/讲解角色内部产出"多元微积分与级数关键结论速查"**（属于稳定知识，模型掌握，不需要外部来源）。
