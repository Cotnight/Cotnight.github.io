## 教学偏好

- 有效的讲法：
  - 目标明确、直接给「考什么、怎么算」，不要展开定理证明。
  - 一次只推进一件事；需要选择时给现成选项让他挑，不要让他自己描述。
  - 用教材原话与原章节顺序（会主动提供教材目录页与老师课件）。
  - 选项式盘问有效：给带一句说明的现成选项，他一轮就能选完（2026-10 建两门课时验证）。
- 容易烦躁的：
  - 长时间的环境/工具折腾（本机 PowerShell 缺失问题耗了多轮，明显不耐烦）。
  - 重复提问同一件事。
- 例子偏好：教材例题与考试题型优先；纯数学抽离的例子不如「考试里会怎么考」有用。

## 学习习惯

- 可投入时间：不固定、弹性（"看哪周有空"）——按"有空多推、没空只复习"的节奏，每次会话至少推进一个节点。
- 在读课程（2026 秋）：复变函数与积分变换、数字电路、离散数学。三门都有期末考试在压着。
- 主线安排：**数字电路为主线**，离散数学在其稳定后接上；两门共用同一份弹性时间。
- 节奏：尚未观察（数字电路首课后再校准）。
- 常见卡点：前置基础整体生疏（复变四级全 B；离散四项前置基本全忘）；具体卡点为级数收敛半径、留数计算、变换公式记忆（复变），组合逻辑化简（数电），证明题起步（离散）。

## 跨科目观察

- 学习载体偏好：接受「可视化 + 代码 + 纸笔」三种实验课混合，不排斥写代码。
- 载体定案（2026-10）：数电与离散的实验课都用 **Python 仿真/工具包**（本机已有 3.13），明确不要为学习再装工具链（不要 Logisim／Verilog 工具链）。
- 两门课有真实接口：离散里的**布尔代数**与数电的逻辑化简是同一套东西，可以互相托底——讲一边时拿另一边的例子对照。
- 提需求的方式极简（如「12b41无」），需要主动校对理解，不要假设自己读对了。
